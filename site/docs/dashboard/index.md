# ts2wasm Dashboard

This page hosts the generated coverage/test dashboard.

## Data source

Dashboard JSON is generated by:

```bash
python scripts/manager.py coverage-dashboard-data
```

The React dashboard is built from `web-ui/` and reads `test-results.json`, `coverage.json`, and `history.json`.

For design and schema details, see `docs/18-web-ui-reporting.md` in the repository root.
