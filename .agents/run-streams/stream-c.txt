# Stream C: Control Flow & Statement Extensions
## Goal
Implement control-flow foundations: try/catch/finally lowering, switch, for variants, do-while, break/continue, throw.

## Context
- Parser side is already present in crates/cli/src/lib.rs
- Implement lowering/backend support in:
  - crates/cli/src/ir/lowered.rs
  - crates/cli/src/backend/stmt_emit.rs
  - crates/cli/src/backend/expr_emit.rs

## Tasks
1. Add/finish LoweredStmt variants for try/catch/finally, switch/case/default, for-in/of, do-while, throw
2. Implement lowering from AST Stmt to LoweredStmt with diagnostics for unsupported edges
3. Implement backend emission for new LoweredStmt variants (structured control flow, no string labels)
4. Ensure break/continue targets are validated and emitted correctly
5. Add/update tests in crates/cli/tests/parser_ast_structures.rs and dedicated integration tests

## Validation
- cargo fmt --all --check
- cargo test -q
- cargo test -q --test parser_ast_structures

## Commit guidance
