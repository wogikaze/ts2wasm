## Notes

- 2026-05-13: Discovered while probing remaining `I-20260513-BRRFMC` builtin fixtures. `fixtures/builtins-and-io/symbol-constructor-basic.ts` builds and runs, but Node stdout is `Symbol(myDesc) Symbol()` while iwasm stdout is `Symbol(myDesc)`.
- 2026-05-13: Root cause was not `Symbol()` string conversion itself; `$symbol_new(undefined)` already emits `Symbol()`. The observable mismatch came from `console.log(s1, s2)` truncating extra arguments in builtin resolution. Console multi-arg lowering now joins arguments with spaces before the existing one-argument `$log` runtime call, and `symbol-constructor-basic.ts` is promoted to Node/iwasm differential coverage.
