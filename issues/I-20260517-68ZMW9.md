## Notes

### Fix implemented

Two DataView-related fixes in the IR layer:

1. **DataView.byteLength accessor** (`property.rs`): Added dedicated arm returning `GetLength` (same as ArrayBuffer). Previously fell through to `Ok(None)`.

2. **set* value argument padding** (`method.rs`): When set* methods are called with only offset (e.g., `dv.setInt8(offset)`), pad the missing value arg with 0:
   - `setInt8`/`setUint8`: pad value = 0 (1 missing arg)
   - `setInt16`/`setUint16`/`setInt32`/`setUint32`/`setFloat32`/`setFloat64`/`setFloat16`: pad value = 0, littleEndian = false (2 missing args)
