## Notes

### Impact (2026-06-15)

Discovered during Error/AggregateError test262 failure analysis. The test262 harness `isConstructor.js` helper (at `reference/test262/harness/isConstructor.js`) depends on `Reflect.construct`:

```js
function isConstructor(f) {
  try {
    Reflect.construct(function(){}, [], f);
  } catch (e) {
    return false;
  }
  return true;
}
```

Without `Reflect.construct`, every test that calls `isConstructor(Error)`, `isConstructor(AggregateError)`, `isConstructor(Boolean)`, etc. will evaluate differently at runtime.

#### Affected Error/AggregateError tests (8 total)

**Error (4 tests):**
- `Error/is-a-constructor.js` — isConstructor(Error) must be true
- `Error/proto-from-ctor-realm.js` — Reflect.construct(Error, [], C) with custom new.target
- `Error/prototype/toString/not-a-constructor.js` — Error.prototype.toString must NOT be constructable
- `Error/isError/is-a-constructor.js` — Error.isError must NOT be constructable

**AggregateError (4 tests):**
- `AggregateError/is-a-constructor.js` — isConstructor(AggregateError) must be true
- `AggregateError/newtarget-proto.js` — new.target prototype for AggregateError
- `AggregateError/newtarget-proto-custom.js` — Reflect.construct with custom prototype
- `AggregateError/newtarget-is-undefined.js` — NewTarget undefined when called without new

#### Also affects (estimated):
- `built-ins/Boolean` — is-a-constructor.js
- `built-ins/Symbol` — is-a-constructor.js
- All builtin constructors with isConstructor checks (~20+ categories)

#### Required implementation
- `Reflect.construct(target, argumentsList, newTarget)` — the core function
- Each builtin constructor's `[[Construct]]` internal method
- Each builtin function's (non-constructor) internal method check
