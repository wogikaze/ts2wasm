## Notes

### Implementation

**`crates/ir/src/lowered/types.rs`** and **`crates/ir/src/lowered/mir.rs`**:
- Added `cause: Option<Box<LoweredExpr>>` to both `LoweredExpr::ErrorNew` and `MirExpr::ErrorNew`
- Updated both conversion directions (lowered→mir, mir→lowered) to pass through the cause

**`crates/ir/src/lowered/resolver/call/constructor.rs`**:
- Extended Error constructor handler to check `args[1]` for a `ResolvedExpr::Object` with a `"cause"` key
- Uses the existing `ResolvedObjectProp::static_key()` / `.value()` helpers

**`crates/backend-wasm/src/expr_emit.rs`**:
- Dynamic `prop_count` (2 or 3 depending on cause presence)
- Uses `frame.child_temp_frame()` for cause emission to prevent `heap_base_tmp` overwrite (nested ObjectNew would clobber the error object address)

**Other backend passes** updated: `runtime_link_plan.rs`, `emitter/strings.rs`, `emitter/class_prototypes.rs`

**Key WAT detail**: When the cause value is itself an ObjectNew (e.g., `{ cause: { nested: true } }`), it must use a child temp frame because ObjectNew emission writes to `heap_base_tmp`, which would overwrite the outer ErrorNew's object address.
