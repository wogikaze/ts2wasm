## Progress

- 2026-06-15 codex: Baseline run: 598 pass, 262 fail (all due to eval.indirect missing)
  - Root cause: COMMON_HOST_PRELUDE defined test262_evalScript with (0, eval)(source),
    which triggered compiler indirect eval lowering, adding $host_eval_indirect import
    to EVERY compiled test262 module. iwasm/WAMR didn't provide this import.
  - Fix: Changed to globalThis.eval(source) which is NOT recognized by the compiler
    as indirect eval, so EvalIndirectHost is no longer bundled into every module.
  - Also added eval.indirect and stringNormalize stubs to iwasm-runner/main.c for
    when the WAMR runner is built and used instead of iwasm CLI.
