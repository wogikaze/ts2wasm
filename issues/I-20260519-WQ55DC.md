### Object.getOwnPropertyNames routing fix (2026-05-20)
- Previously `getOwnPropertyNames` was routed to `$object_keys` which filters by enum-only
- Added new `ObjectGetOwnPropertyNames` RuntimeFn variant with dedicated WAT function
- `$object_get_own_property_names` returns all own string property names (including non-enumerable), excluding symbols

### Object.create(props) / Object.defineProperties fix (2026-06-14)
- **ObjectCreate handler** in `native_lowered.rs`: Previously dropped the second (properties) argument entirely and only called `$object_create(proto)`. Now calls `$object_define_properties(obj, properties)` when properties arg is present.

- Added `ObjectDefineProperties` to `OBJECT_CREATE_DEPS` in `runtime_fn.rs`.
- All 88 part_1 tests pass, all object kernel/descriptors/methods tests pass.
