## Evidence

All 40+ JSON.stringify tests pass, covering:

### Replacer arrays (compile-time key extraction)
- Static string keys: `["a"]` ✓ (replacer-array.ts, replacer-array-multikey.ts)
- Numeric keys: `[1, "a"]` ✓ (replacer-array-number.ts)
- Boxed keys: `[new Number(1), new String("a")]` ✓ (replacer-array-boxed.ts)
- Ignored entries: booleans, null, undefined, functions, Symbol, ArrowFn ✓ (replacer-array-ignored.ts)
- Boxed Object coercion: `[new Object(2)]` ✓ (replacer-array-boxed-unsupported.ts)

### Replacer functions (runtime dispatch by FuncId)
- Named function by identifier: `JSON.stringify(obj, func)` ✓ (replacer-function-keep.ts)
- Filtering via return undefined ✓ (replacer-function-drop.ts)
- Transform via return value ✓ (replacer-function-transform.ts)
- Root holder access via `this[""]` ✓ (replacer-function-root-holder.ts)
- Arrow function replacers ✓ (replacer-array-ignored.ts)

### Space parameter
- Numbers (truncated 0-10): `2` ✓ (space.ts)
- Strings (first 10 chars): `">>"` ✓ (space-string.ts)
- Booleans: `true`/`false` ✓ (space-boolean.ts)
- Boxed Number/String/Boolean/Object ✓ (space-boxed-symbol.ts)
- Ignored: functions, Symbol, objects ✓ (space-object-function.ts)

### Unsupported forms (explicit diagnostic referencing issue-052)
- Dynamic replacer arrays (variable refs as elements): unsupported diagnostic
- Replacer functions with rest/arguments params: unsupported diagnostic
- Non-null/undefined non-array/non-function replacer values: unsupported diagnostic

### Gap: toJSON interop
- `value.toJSON(key)` is NOT called before replacer/serialization
- Tracked by test262 replacer-function-tojson.js
