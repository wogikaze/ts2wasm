## Status

A new Rust-native test262 reference coverage runner is now operational at `crates/cli/tests/reference_coverage.rs`. It uses in-process compilation (no Python, no IPC) and a persistent Node.js oracle for semantic comparison.

## Capabilities

- **cargo nextest integration**: `cargo nextest run -p ts2wasm-cli --test reference_coverage`
- **In-process compilation**: No Python/`ts2wasm server` subprocess, direct Rust API call
- **Persistent Node.js oracle**: Single node process with `vm.createContext` per file, ~0 startup cost vs ~35ms/file subprocess
- **58 test262 categories**: 21 pass (compile), 33 semantic fail, 4 timeout
- **Full run**: ~7 minutes (423s) for all 58 categories with semantic checking
