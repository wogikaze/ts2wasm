Title: Architecture wave: runtime heap and GC layout contract
Summary: Capture heap kinds, root categories, layout descriptors, and GC canaries as executable ABI data.
Next: Implement runtime layout descriptor, snapshots, and GC root/pressure tests.

---

## Acceptance
- Add machine-readable runtime heap/layout descriptors for heap kinds, root categories, object/array/string/function references, and GC scanner expectations.
- Add layout snapshots/canaries that fail when runtime ABI or GC layout changes without an intentional snapshot update.
- Add GC pressure/root survival tests covering arrays, objects, globals, locals/activation frames, and allocation thresholds where supported.
- **Typed heap allocation (`$alloc_heap_kind`)**: Add WAT helper `$alloc_heap_kind(param $size i32)(param $kind i32)(param $reserved i32)(result i32)`. Keep `$alloc_heap(size)` as backward-compat wrapper for internal/scratch allocations. Add `HeapKind` Rust enum in `runtime-abi` with discriminants matching `Layout::GC_KIND_*`. Migrate string/array/object/closure/BigInt allocation sites from manual kind patching to `$alloc_heap_kind`. Add structural test rejecting manual kind stores outside allowlist.
- **Array GC scanner presence bitmap fix**: Rewrite `$gc_mark_array_payload` to load `presence_word_count` from `ARRAY_PRESENCE_WORD_COUNT_OFFSET` and `elements_offset` from `ARRAY_ELEMENTS_OFFSET_OFFSET`. For each index `i`, compute `word_index = i >> 5`, `bit = 1 << (i & 31)`. Only call `$gc_mark_value` for present elements at `payload + elements_offset + i * 4`. Add sparse-array GC pressure fixture where holes must not be scanned.
- **GC threshold normalization**: Replace backend `Layout::GC_THRESHOLD * 2` with `Layout::GC_THRESHOLD` directly. Add WAT structural test `alloc_heap_uses_layout_gc_threshold` that emitted constant equals ABI snapshot value. Document threshold semantics (collection triggers at pressure + headroom, last-chance at max cap, OOM as `unreachable`).
