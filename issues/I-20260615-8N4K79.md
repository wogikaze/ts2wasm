### AggregateError root cause analysis (2026-06-15)
All 17 mismatches are caused by the same issue: AggregateError resolves to a string display value at runtime. Object.getOwnPropertyDescriptor on a string doesn't return constructor property descriptors. Fix requires adding a RuntimeFn that creates a proper AggregateError constructor global object with correct .length (2), .name, .prototype, and [[Construct]] behavior.

The 5 harness-fixed tests (cause-property, errors-iterabletolist, message-tostring-abrupt*) now PASS the semantic check because they don't rely on property descriptors of the constructor itself.

### Deep root cause analysis — 22 Error + 17 AggregateError infrastructure gaps (2026-06-15)

After implementing `[[ErrorData]]` detection in `$object_to_string` and adding node_diff fixtures, all 39 mismatches trace to **3 fundamental runtime infrastructure gaps** that affect ALL builtin categories, not just Error/AggregateError:

#### Gap 1: Object.getOwnPropertyDescriptor (12 Error + 8 AggregateError tests)
Every `verifyProperty()` call in test262 harness depends on `Object.getOwnPropertyDescriptor`. Tests that fail:
- `Error/prop-desc.js`, `Error/prototype/constructor/prop-desc.js`
- `Error/prototype/toString/prop-desc.js`, `Error/prototype/toString/length.js`, `Error/prototype/toString/name.js`
- `Error/instance-prototype.js` (uses verifyProperty for Error.prototype)
- `Error/prototype/S15.11.3.1_A*.js` (uses deprecated verifyNotConfigurable/verifyNotWritable)
- `Error/isError/prop-desc.js`
- `AggregateError/prop-desc.js`, `AggregateError/prototype/prop-desc.js`, `AggregateError/prototype/constructor.js`
- `AggregateError/length.js`, `AggregateError/name.js`
- `AggregateError/message-method-prop-cast.js` (uses verifyProperty)
- Also affects: Boolean (12 tests), Symbol (many), Reflect (many), Number (many)

#### Gap 2: Reflect.construct / isConstructor (4 Error + 4 AggregateError tests)
The `isConstructor()` helper in test262 harness depends on `Reflect.construct`. Tests that fail:
- `Error/is-a-constructor.js`, `Error/proto-from-ctor-realm.js`
- `Error/prototype/toString/not-a-constructor.js`
- `AggregateError/is-a-constructor.js`, `AggregateError/newtarget-proto*.js`, `AggregateError/proto-from-ctor-realm.js`
- `Error/isError/is-a-constructor.js`
- Also affects: Boolean, Symbol, and all builtin constructors

#### Gap 3: Proxy (1 Error + 1 AggregateError test)
- `Error/cause_abrupt.js` — uses `new Proxy({}, { has(...) })` for abrupt completion testing
- `AggregateError/newtarget-proto-custom.js` — uses Proxy for custom new.target

#### Gap 4: Object.prototype.toString [[ErrorData]] + Symbol.toStringTag (3 Error tests)
- `Error/tostring-1.js`, `Error/tostring-2.js` — IR resolves `Error.toString()` to `ErrorToString` at compile time, so the `$object_to_string` [[ErrorData]] fix is bypassed
- `Error/prototype/no-error-data.js` — requires `Object.defineProperty` and `Symbol.toStringTag` support
