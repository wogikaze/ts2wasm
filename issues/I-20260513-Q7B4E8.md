### Implementation notes
- The WAT regex engine (`crates/backend-wasm/src/runtime/regexp/emit.rs`) now correctly parses flags from pattern strings. dotAll (s flag) works via existing `$dot_all` parameter in `$regexp_match_inner`. Sticky flag requires lastIndex object state which does not exist in the current string-only RegExp model.
- Named groups and lookahead/lookbehind require fundamental changes to the matching algorithm (NFA simulation) since the current engine is a simple backtracking matcher without group capture state.
- Unicode support requires multi-byte character handling which conflicts with the byte-level string model.
