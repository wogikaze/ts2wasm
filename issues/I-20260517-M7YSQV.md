## Notes

### Fix applied
Removed `min_required_params` lower-bound arity check from three locations in both `validate.rs` (lowered) and `mir_validate.rs` (MIR):

1. **FunctionCallKind::User**: JS semantics allow calling functions with fewer args than declared params — missing params become `undefined` at runtime.
2. **FunctionCallKind::Builtin**: Only upper-bound check remains (too many args), lower-bound removed.
3. **Constructors**: Same JS semantics — constructors accept any number of args.
