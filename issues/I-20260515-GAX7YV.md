Title: IR: instanceof with dynamic/unsupported class constructors
Summary: Support instanceof right-hand side beyond statically known class constructors

## Problem

instanceof with a RHS that is not a statically known class constructor was not supported. The IR lowering had only a static path for known class constructors via `RuntimeFn::InstanceOf`.

## Steps

1. Add dynamic fallback in `lower_instanceof_expr` for non-static RHS
2. Wire `RuntimeFn::SymbolHasInstance` through the runtime catalog
3. Implement `emit_symbol_has_instance` in the host dispatch layer
4. Add fixture and test for dynamic instanceof
