## Notes

### 2026-05-16: Fix implemented

Changed `lower_nested_function` and `lower_nested_function_with_receiver` in `function.rs` to allow `this` in nested functions without explicit `this` parameter.

**Problem**: When a non-arrow nested function referenced `this` without an explicit `this` parameter in non-strict mode, the IR resolver emitted `issue-5179` error ("'this' implicitly has type 'any'").

**Fix**: Instead of erroring, let `this` references fall through to `lower_this_expr` which already handles unresolvable `this` by returning `undefined`. This matches the existing strict-mode behavior.

**Changed file**: `crates/ir/src/lowered/resolver/function.rs`
- Line 169-192: Removed `return Err(...)` for non-strict `this` usage
- Line 434-443: Same fix in `lower_nested_function_with_receiver`
