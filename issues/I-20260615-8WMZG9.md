Title: Runtime: Object.getOwnPropertyDescriptor / property descriptor infrastructure
Summary: All ~17 verifyProperty tests in Error/AggregateError fail because Object.getOwnPropertyDescriptor is not implemented. Also blocks Boolean, Symbol, and all builtin constructor property descriptor tests across test262.
Next: Implement Object.getOwnPropertyDescriptor and Object.defineProperty for plain objects, then extend to builtin constructors

---

## Notes

### Impact (2026-06-15)

Discovered during Error/AggregateError test262 failure analysis. Every test262 harness `verifyProperty()` call depends on `Object.getOwnPropertyDescriptor`. This is the single largest blocker for builtin constructor test262 coverage.

#### Affected Error/AggregateError tests (20 total)

**Error (12 tests):**
- `Error/prop-desc.js` — global Error property descriptor
- `Error/prototype/constructor/prop-desc.js` — Error.prototype.constructor descriptor
- `Error/prototype/toString/prop-desc.js` — Error.prototype.toString descriptor
- `Error/prototype/toString/length.js` — Error.prototype.toString.length descriptor
- `Error/prototype/toString/name.js` — Error.prototype.toString.name descriptor
- `Error/instance-prototype.js` — Error.prototype descriptor (uses verifyProperty)
- `Error/prototype/S15.11.3.1_A1_T1.js` — Error.prototype DontDelete (uses verifyNotConfigurable)
- `Error/prototype/S15.11.3.1_A2_T1.js` — Error.prototype DontEnum (uses propertyIsEnumerable)
- `Error/prototype/S15.11.3.1_A3_T1.js` — Error.prototype ReadOnly (uses verifyNotWritable)
- `Error/the-initial-value-of-errorprototypemessage-is-the-empty-string.js` — uses hasOwnProperty
- `Error/isError/prop-desc.js` — Error.isError descriptor
- `Error/length.js` — Error.length

**AggregateError (8 tests):**
- `AggregateError/prop-desc.js` — global AggregateError property descriptor
- `AggregateError/prototype/prop-desc.js` — AggregateError.prototype descriptor
- `AggregateError/prototype/constructor.js` — AggregateError.prototype.constructor descriptor
- `AggregateError/length.js` — AggregateError.length
- `AggregateError/name.js` — AggregateError.name
- `AggregateError/message-method-prop-cast.js` — uses verifyProperty

#### Also affects (estimated):
- `built-ins/Boolean` — ~12 verifyProperty tests
- `built-ins/Symbol` — many property descriptor tests
- `built-ins/Number` — property descriptor tests
- `built-ins/Reflect` — property descriptor tests
- All builtin constructors with `.name`/`.length`/`.prototype` descriptor checks

#### Required RuntimeFn (estimate):
- `Object.getOwnPropertyDescriptor(obj, prop)` — return undefined or {value, writable, enumerable, configurable} descriptor object
- `Object.defineProperty(obj, prop, desc)` — define or modify property with descriptor
- `Object.prototype.propertyIsEnumerable(prop)` — used by verifyProperty
- `Object.prototype.hasOwnProperty(prop)` — used by verifyProperty and individual tests

#### Dependency chain for `verifyProperty`:
```
verifyProperty(obj, name, expected)
  → Object.getOwnPropertyDescriptor(obj, name)  ← CRITICAL: must return proper descriptor
  → Object.defineProperty (for restore step)
  → delete obj[name] (for isConfigurable check)
  → for...in loop (for isEnumerable check)
  → Array.isArray
  → Object.prototype.hasOwnProperty.call
  → Object.prototype.propertyIsEnumerable.call
```
