## Notes

### Goal

Make native MIR independently safe to pass across phase boundaries.

### Acceptance

- `validate_mir` checks native local IDs, function IDs, module IDs, class/function references, top-level return, and invalid control-flow shape.
- `Validated<MirProgram>::new_mir` returns fatal `InvariantViolation` for backend-crashing shapes.
- MIR dump/snapshot tests distinguish native MIR from HIR and legacy LoweredProgram debug output.
- Invalid-ID and invalid-control-flow tests fail for the right diagnostic code.

### Non-goals

- No native MIR emitter.
- No semantic feature expansion.

## Evidence

- native MIR validator, MIR dump snapshot coverage, and invalid-ID/control-flow tests passed
