## Notes

### 2026-05-16 — WAMR VMcore runner confirmed working

Native WAMR VMcore persistent runner implemented at `crates/iwasm-runner/main.c`.
Links against `libiwasm.a` (pre-built, same interpreter as iwasm CLI).

Benchmark (10 test262 wasm files, release build):
- iwasm CLI: 582ms avg (process spawn + runtime init dominate)
- WAMR runner: 10ms avg (58x faster, runtime persistent)

53K projection (24 workers):
- WAMR runner semantic: ~29s
- wasm emit: ~114s
- **total semantic fast: ~143s (< 300s!)**

### Previous attempt (now superseded)

wasmtime-based runner was 1.3x slower than iwasm CLI (763ms vs 585ms).
The correct approach is native WAMR VMcore, not wasmtime.

### Build

```bash
gcc -O2 -o ts2wasm-iwasm-runner main.c \
    -I/path/to/wasm-micro-runtime/core/iwasm/include \
    -I/path/to/wasm-micro-runtime/core/shared \
    -I/path/to/wasm-micro-runtime/core/shared/utils \
    -I/path/to/wasm-micro-runtime/core/shared/platform/include \
    -I/path/to/wasm-micro-runtime/core/shared/platform/linux \
    /path/to/wasm-micro-runtime/libiwasm.a \
    -lm -lpthread -ldl -s
```
