### Missing features

- Computed property names: `{ [expr]: value }`
- Method definitions: `{ method() {} }`
- Getter/setter: `{ get x() {}, set x(v) {} }`
- __proto__: `{ __proto__: otherObj }`
- Object spread: `{ ...obj }`
- Shorthand properties: `{ x, y }` (may already work)
