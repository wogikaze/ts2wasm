## Notes

### Goal

Make the current HIR boundary measurable. The important result is not that every JavaScript feature lowers to HIR, but that every supported and unsupported case is deliberate.

### Acceptance

- Document supported HIR statements and expressions against the feature matrix.
- Add fixtures for supported `let`, assignment, expression, `if`, `while`, `return`, constants, locals, property/index, builtin/user/method calls.
- Add rejection fixtures for nested function, ternary, assignment expression, and dynamic calls where HIR intentionally rejects them.
- Ensure unsupported forms produce stable diagnostics rather than silent fallback in HIR-only validation.
- Record commands and any unavailable tooling caveat.

### Non-goals

- No broad HIR feature expansion in this slice.
- No native MIR model changes.
