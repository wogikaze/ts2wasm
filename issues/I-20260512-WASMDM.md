## Notes

### Goal

Make typed WasmIR migration concrete without attempting a whole-backend rewrite.

### Acceptance

- Pick one bounded low-conflict domain, such as a small runtime helper group or a focused emitter path.
- Replace raw WAT string assembly with `WasmInstr`, `WasmFunction`, `WasmModule`, or `WatWriter` typed helpers where practical.
- Keep audited `Raw` escape hatches only where no typed variant exists yet.
- Add parity tests proving the generated WAT remains valid for the selected domain.
- Document remaining raw WAT escape hatches for that domain.

### Non-goals

- No MIR default pipeline switch.
- No full backend WAT template replacement.
