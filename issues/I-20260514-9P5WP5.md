## Notes

## Evidence

### Implemented

- **Format substitution** (`%s`, `%d`, `%i`, `%f`, `%o`, `%O`): Applied at compile time for static format strings with static arguments.
- **Multi-arg joining**: All static arguments joined with spaces (e.g., `console.log("a", 1, true)` → `"a 1 true"`).
- **console.assert**: Routes to stderr (ConsoleError) with "Assertion failed: " prefix for falsy conditions.
- **console.trace**, **console.timeLog**: Added to supported methods list (no longer UnsupportedSyntax).
- **console.group/groupEnd/groupCollapsed/count/time/timeEnd**: Properly routed through BuiltinId variants.
- **console.clear**: Supported as no-op.
- **New BuiltinId variants**: ConsoleGroup, ConsoleGroupEnd, ConsoleGroupCollapsed, ConsoleTime, ConsoleTimeLog, ConsoleTimeEnd, ConsoleCount, ConsoleCountReset, ConsoleTrace.

### Remaining (not yet implemented)

- **Group indentation**: WAT-level indent tracking (requires new RuntimeFn + WAT global).
- **Timer tracking**: WAT-level timer with WASI clock_time_get (requires new RuntimeFn + memory table).
- **Counter tracking**: WAT-level counter with label→count mapping.
- **Object/array formatting**: Dynamic args (e.g., `{a: 1}`, `[1,2,3]`) not formatted.
- **console.assert with true condition**: Already silent (correct).
