## Notes

### Fix: DataViewGetBuffer/DataViewGetByteOffset routing (2026-05-21)

**Problem**: DataView.buffer returned `undefined` and DataView.byteOffset returned `0` because
the IR property resolver did not route these to runtime functions, and the RuntimeFn enum
did not have the `DataViewGetBuffer`/`DataViewGetByteOffset` variants in this worktree.

**Root cause**: This worktree was created from an older commit before these variants existed.
The main repo already had the enum variants and WAT implementations, but they were not
present in the worktree.

**Fix** (7 files, commit `6c6e3cdcc`):
1. Added `DataViewGetBuffer` and `DataViewGetByteOffset` to RuntimeFn enum + all wiring
   (from_name, domain, globals, emission_order, spec, manifest)
2. Added WAT emission functions `emit_dataview_get_buffer` and `emit_dataview_get_byte_offset`
   in runtime_typed_arrays.rs
3. Added dispatch arms in runtime_dispatch_array.rs
4. Already present in this worktree from previous work: property.rs routes
   DataView.buffer/byteOffset to runtime functions, catalog.rs entries
