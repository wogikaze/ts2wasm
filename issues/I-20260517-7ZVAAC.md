## Notes

### 2026-05-17: Function identifier callbacks in array methods

Implemented `ResolvedExpr::Ident(name)` resolution in `lower_array_callback_method` and
extended the dispatch guard in `lower_mcall_dispatch_early` to accept named function
references as array method callbacks.

**Before**: `arr.forEach(myFunc)` fell through to WAT NOP stubs that accepted the callback
parameter but never called it.

**After**: Named function references (`ResolvedExpr::Ident(name)`) that resolve to known
`FuncId` values use the same IR-level WhileLoop expansion as ArrowFn and FunctionExpr
callbacks. The callback is actually called for each element.

This only addresses the case where the callback is a simple function identifier.
Other callback forms (property access, computed expressions) still fall through to WAT stubs.
