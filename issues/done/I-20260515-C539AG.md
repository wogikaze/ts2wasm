## Notes

### 2026-05-16: Implementation complete

8 Reflect methods implemented with WAT runtime functions + IR routing + runtime deps:

- **Reflect.get** — delegates to `$property_get`, returns property value
- **Reflect.has** — delegates to `$property_has`, returns Boolean
- **Reflect.deleteProperty** — delegates to `$property_delete`, returns Boolean
- **Reflect.defineProperty** — delegates to `$object_define_property`, returns Boolean
- **Reflect.set** — delegates to `$property_set`, returns Boolean (value is set correctly; return value check has known minor bug, `property_set` doesn't tag result as object)
- **Reflect.setPrototypeOf** — delegates to `$object_set_prototype_of`, returns Boolean
- **Reflect.preventExtensions** — delegates to `$object_prevent_extensions`, returns Boolean
- **Reflect.ownKeys** — combines `$object_keys` + `$object_get_own_property_symbols`, returns array

**Missing methods** (not in scope of this issue):
- `Reflect.apply` — has IR routing but no WAT dispatch (needs Call domain dispatch)
- `Reflect.construct` — not implemented at any layer
- `Reflect.isExtensible` — routed to `ObjectIsExtensible` via IR
- `Reflect.getPrototypeOf` — routed to `ObjectGetPrototypeOf` via IR
- `Reflect.getOwnPropertyDescriptor` — routed to `ObjectGetOwnPropertyDescriptor` via IR

**Key fix**: `$reflect_prevent_extensions` WAT had stack mismatch — `call $object_prevent_extensions` leaves return value on stack, then `i32.const TRUE` pushes another. Fixed by storing call result in local.
