## Notes

### 2026-05-16: Audit complete — already fully implemented

Spread/rest in all three requested contexts (call, array, destructuring) is already implemented and tested.

**Call argument spread** (`f(...args)`):
- Parser: `Expr::Spread` in `expressions_main.rs:1257-1589`
- IR resolved: `ResolvedExpr::Spread` in `builtin_resolver.rs:2157`
- IR lowered: `lower_function_call_args` / `lower_call_args` in `call/spread.rs`
- Backend: runtime functions `ArrayPushOrSpread`, `SpreadViaIterator`

**Array literal spread** (`[1, ...arr, 3]`):
- Parser: `ArrayLiteralElement::Spread` in `expressions_main.rs:2006`
- IR lowered: `lower_array_literal_elements` in `array.rs:38-109` (dense array, Set, Map, string, literal, iterator strategies)

**Object literal spread** (`{...obj}`):
- Parser: `OBJECT_SPREAD_SENTINEL` key pattern in `expressions_main.rs:2044`
- IR lowered: `lower_object_literal_props` in `object.rs` (static + runtime `ObjectSpread`)
- Backend: WAT runtime function `$object_spread`

**Destructuring rest patterns** (`[a, ...rest] = arr`, `{a, ...rest} = obj`):
- Parser: `parse_array_binding_pattern` / `parse_object_binding_pattern` in `binding_patterns.rs`
- IR lowered: `lower_array_binding_declaration` (ArraySlice) + `lower_object_rest_binding_declaration` in `binding.rs`
- Tested: `destructuring-binding-rest-runtime.ts`, `destructuring-binding-object-rest-runtime.ts`

**Fixtures:** 30+ spread/rest fixtures in `fixtures/core-semantics/` and `fixtures/spread-args/`
