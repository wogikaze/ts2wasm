## Problem

Node host import growth is a documented risk. Currently `host-deny.py` is info-oriented and there is no checked-in host import baseline. New Node host imports can be added without architectural approval. A hard baseline gate is needed.

## Steps

1. Commit sorted `artifacts/abi/host-imports-baseline.json` with entries: `module`, `name`, `abi`, `wat_symbol`, `capability`, `reason_owner`
2. Add `scripts/check/host-import-baseline.py` and `check-host-import-baseline` mise command
3. Make `host-deny.py --compile` fail when a host-free fixture imports module `host`; keep `--report-only` for exploration
4. Add diff tests for added/removed/changed imports

## Acceptance
