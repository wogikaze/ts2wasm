### 2026-05-15 resolution
- Root cause: `new Array()` (no args) produced `ArrayNewSparse` lowered expr, which was not recognized by `is_known_array_expr` or `resolved_expr_produces_dense_array`. This caused `push` to route to `$array_push` (object-path function with allocation bug) instead of `$array_push_grow` (array-path function).
- Fix 1 (constructor.rs): Changed `new Array()` no-args from `ArrayNewSparse` to `ArrayNew`
- Fix 2 (facts.rs): Added `ResolvedExpr::New { class_name: "Array", args: [] }` case to `resolved_expr_produces_dense_array`
