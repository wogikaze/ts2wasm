## Summary

Add diagnostic attribution that explains why ABC451 depth-8 result arrays are
not at the heap top when `$array_push_grow` needs fallback allocation/copy.

Problem: issue 365 proves the dominant array-growth pressure is
`top_miss_reason=non_top_heap`, but the current telemetry does not say which
allocation/lifetime pattern separates those arrays from the heap top before
growth.

## Current failure

The current issue-365 baseline at the 100000-event diagnostic budget is:

```text
command: mise run abc451-runtime-costs -- --event-budget 100000 --timeout 30
result: pass; alloc_array_growth_bytes=362976; alloc_array_growth_calls=2648; copy_array_growth_bytes=181008; copy_array_growth_calls=2648; allocation_requested_bytes=521193; sweep_visits=58859; free_list_scan_visits=0; top_miss_reason=non_top_heap
```

The focused gate still times out:

```text
command: cargo nextest run -p ts2wasm-cli abc451_depth8_live_set_fixture_matches_node_output_under_iwasm
result: fail; known iwasm timeout recorded in issue 365
```

## Desired final state

`mise run abc451-runtime-costs -- --event-budget 100000 --timeout 30` reports
non-top array separation attribution precise enough to choose the next safe
issue-365 implementation slice, without changing runtime behavior.

The after metrics for this attribution-only slice must keep the existing
aggregate runtime counters equal to the baseline unless the implementation
explicitly proves a no-regression reason:

```text
alloc_array_growth_bytes=362976
alloc_array_growth_calls=2648
copy_array_growth_bytes=181008
copy_array_growth_calls=2648
allocation_requested_bytes=521193
sweep_visits=58859
free_list_scan_visits=0
top_miss_reason=non_top_heap
```

## Scope

In scope:

- [x] Add default-off telemetry that classifies non-top `$array_push_grow` fallback copies by the reason the array is no longer the heap-top object.
- [x] Distinguish at least intervening allocation after array creation, recursive temporary/result array pressure, retained live arrays, and unknown/unclassified separation.
- [x] Surface the new attribution in `mise run abc451-runtime-costs` output at the 100000-event budget.
- [x] Preserve all existing aggregate counters and runtime behavior.

Out of scope:

- Changing array representation.
- Changing `$array_push_grow` growth policy, copy policy, memory caps, or timeouts.
- Weakening the ABC451 depth-8 gate.
- Parser, BigInt, reference-triage, or unrelated fixture work.
