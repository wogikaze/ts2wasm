## Notes

### Goal

Start shrinking `crates/backend-wasm/src/mir_emit.rs` from bridge-only behavior into a real native MIR emitter.

### Acceptance

- Direct native MIR emission covers constants, local load/store, expression statements, `if`, `while`, `return`, runtime calls, builtin calls, and user calls for the supported HIR slice.
- Unsupported MIR variants return a precise diagnostic or route through an explicitly named compatibility fallback.
- Parity tests compare output behavior with the legacy `Validated<LoweredProgram>` path for selected fixtures.
- `emit_mir_wat` remains non-default until the P16 gate passes.

### Non-goals

- No default compiler pipeline switch.
- No full WAT runtime template rewrite.
