## Notes

### Initial investigation (2026-05-19)

**Analysis of 57 test262 String failures:**
- 54 "output mismatch" failures: ALL Annex B non-standard methods (HTML wrappers, substr, trimLeft/trimRight) — property descriptor tests, not WAT fixes
- 3 crash/assertion failures: All use `$262.IsHTMLDDA` with `@@replace`/`@@split` protocol tests — our runtime doesn't implement this protocol
- All 695 node_diff tests pass (0 failures) — basic string functionality works

**Root cause of WASM crash (fixed):**
- `emit_regexp_match_from` in `runtime/regexp/emit.rs` is called from TWO places: `emit_string_split` and `emit_string_replace`
- Had NO duplicate-emission guard — if both StringSplit and StringReplace are needed in the same program, `$regexp_match_from` would be emitted twice
- This produces invalid WAT and causes "WASM module load failed: type mismatch" crashes
- Fixed by adding guard: `if wat.contains("$regexp_match_from") { return; }`

### Commits
- `751fbdf3f` fix: String.prototype.replace - prevent duplicate $regexp_match_from WAT emission

### Fix 2: position parameter for indexOf/lastIndexOf (2026-05-20)

**Root cause:** `$string_index_of` and `$string_last_index_of` WAT functions accepted only 2 params (haystack, needle) but the JS spec has (searchString, position). When test262 passed a position argument, the WASM function signature mismatch caused a validation crash (extra stack value left after call).

**Fix:**
- `$string_index_of`: Added position param, decode from tagged value, clamp to [0, h_len], search from clamped position. Empty needle returns clamped position (per spec). Added needle-longer-than-haystack guard.
- `$string_last_index_of`: Added position param, decode from tagged value, clamp to [0, h_len], limit backward search to min(position, h_len - n_len). Empty needle returns clamped position. Added guard.
- `emit_runtime_call_expr`: When args.len() == 2 (no position), default to undefined (0) for indexOf/lastIndexOf, matching existing pattern for includes/startsWith/endsWith.

**Commit:** `d257dcddc`
