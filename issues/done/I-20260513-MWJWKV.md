## Notes

- Split from `I-20260513-HAY3Q2`: that slice replaces compile-time `next_index` with runtime state locals for straight-line generators, multiple iterator instances, aliasing, direct `gen().next()`, and trailing completion side effects.
- Remaining control-flow work needs generator body lowering to preserve branch/loop execution across suspend/resume rather than collecting only straight-line resume chunks.
- Implemented a bounded control-flow extension for the existing runtime-state generator step collector:
  - single-yield `if`/`else` branches lower into a ternary yield value guarded by the iterator state label;
  - static counter `for` loops lower into repeated resume states with the loop update executed before subsequent yields and once before completion.
- Added Node differential fixtures for branch yields and multi-step loop yields.
