## Notes

### 2026-05-14 fix

Root cause was in the runtime parseInt path, not the parser: `$parse_int_string`
only recognized ASCII space, only accepted A-F/a-f as alphabetic digits, and
returned tagged zero instead of the NaN sentinel for invalid digit/radix cases.
The fix expands radix digits through Z/z, recognizes the UTF-8 whitespace
sequences covered by `S15.1.2.2_A2_T10.js`, and returns the runtime NaN sentinel
for no-digit and invalid-radix results.
