## Notes

- 2026-05-13: Added static lowering for direct function declaration `fn.call(thisArg, ...)`, `fn.apply(thisArg, arrayLiteralOrDenseArrayLocal)`, and immediate `fn.bind(thisArg, ...bound)(...)` calls. Receiver-aware functions now receive the supplied thisArg through the existing function signature path.
- 2026-05-13: Added static local tracking for escaped bound functions (`const f = fn.bind(...); f(...)`) when the bound target is a known function declaration. Calls expand the captured receiver and partial arguments at the call site.
- 2026-05-13 codex: Added source-visible escaped `Function.prototype.call/apply.bind(fn)` and `Function.prototype.bind.call(fn, thisArg, ...args)` tracking. Reused locals now expand through the existing user-call path and match Node for receiver-aware calls, apply arrays, and partial bind reuse.
- 2026-05-13 codex: Split bound constructors and new-target preservation into `I-20260513-G84CR3` because it needs real construct-call/function-object support beyond this issue's call/apply/bind callable path.
