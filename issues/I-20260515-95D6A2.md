## Acceptance
- Emit TypeScript erasure/rejection decision records for tsc/tsgo coverage runs.
- Treat parser smoke as a first-class non-semantic fixture class and keep TypeScript oracle isolation explicit.
- **Parser smoke test class**: Add `crates/cli/tests/parser_smoke.rs` that runs pass/fail fixtures through the parser only (no build/runtime). Add `TypeScriptBoundaryRecord` test helper JSON schema: `{"source","construct","category","runtime_nodes_emitted","diagnostic"}`. Categories: `parse-and-erase`, `parse-and-preserve`, `parse-and-lower`, `reject-as-unsupported`.
- **Fixture additions**: Add fixtures for `type alias`, `interface`, `type annotation`, `as`, `satisfies`, `generic type parameters`, `declare class/function/const`, and rejected ambient initializer. Assert erased constructs produce `runtime_nodes_emitted == 0`. Assert rejected forms use exact `DiagCode`: `UnsupportedTypeScriptSyntax`, `UnsupportedModule`, or `UnsupportedRuntimeSubset`.
- Attribute frontend coverage reasons to parser syntax, TypeScript erasure, unsupported builtin, harness, reference, or unknown categories.
- Run: `cargo test -p ts2wasm-frontend parser`
- Run: `cargo nextest run -p ts2wasm-cli --test parser_smoke`
- Run: `python3 scripts/manager.py check diagnostics`
- Run: `python3 scripts/manager.py check records -- --self-test`
- Run: `mise run reference-coverage -- tsc --limit 30`
- Run: `mise run reference-coverage -- tsgo --limit 20`
