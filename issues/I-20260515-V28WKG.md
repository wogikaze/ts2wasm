### 2026-05-15 implementation verification
All Promise and async/await features verified:

**WAT Runtime Functions** (in `crates/backend-wasm/src/runtime_promise.rs`):
- `$promise_constructor` — allocates 4-slot promise array (state, result, onFulfilled, onRejected)
- `$promise_resolve` — creates fulfilled promise with value
- `$promise_reject` — creates rejected promise with reason
- `$promise_then` — registers onFulfilled/onRejected callbacks based on state
- `$promise_catch` — registers onRejected callback for rejected/pending
- `$promise_finally` — registers same callback for both slots when pending
- `$promise_all` — iterates promises, collects resolved values, short-circuits on reject
- `$promise_race` — returns first resolved/rejected promise, or first element
- `$promise_any` — returns first fulfilled, or AggregateError rejection
- `$promise_allSettled` — maps each promise to {status, value/reason} record
- `$promise_withResolvers` — wraps Promise constructor in resolver/rejecter object
- `$aggregate_error` — creates AggregateError with errors, message, name

**Async function lowering** (in `crates/backend-wasm/src/emitter/functions.rs`):
- Allocates state-machine frame: [state, cr_status, cr_value]
- Initializes state=0 (pending)
- Epilogue checks `$exception_pending`, stores completion in frame, sets state=1
- Returns frame pointer (not UNDEFINED) for async functions

**Await expression** (in `crates/ir/src/lowered/resolver/expr/control.rs`):
- `lower_await_expr` creates `PromiseGetValue` for non-trivial expressions
- Backend `PromiseGetValue` handler calls `task_poll` + `task_result`

**Nested async functions** (fix in `crates/ir/src/lowered/resolver/function.rs`):
- `is_async` now propagated through `lower_nested_function` and `lower_nested_function_with_receiver`
