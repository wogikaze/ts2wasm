## Notes

### Fixed: Number static method function tokens (commit fb774578b)

Root cause: `builtin_function_token_value()` in `program_builtins.rs` had no entries for
`isNaN`, `isFinite`, `isInteger`, `isSafeInteger`, so property access on `Number.isNaN` (etc.)
returned undefined, causing ~40 "TypeError: not a function" test262 failures.

Fix: Added 4 sentinel payload constants in `value.rs` using reserved out-of-range slots
(NAN_PAYLOAD+12 through +15) and wired them into `builtin_function_token_value()`.

Note: `resolve_method_to_runtime_fn()` already routed these method calls correctly;
only property access was broken.

Validated: `cargo nextest run -p ts2wasm-cli --test node_diff` => 696 passed, 1 skipped
