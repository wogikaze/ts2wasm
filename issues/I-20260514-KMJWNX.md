### Fix applied (2026-05-14)

**Root cause**: `lowers_to_top_level_statement()` in `crates/compiler/src/stages/lower.rs` returned `true` for `Stmt::AmbientValueDecl`, causing `rewrite_static_module_body_for_build` to increment `lowered_statement_index` for ambient declarations. But the actual lowering loop in `lower_program_with_module_url` skips ambient declarations — they only call `resolver.declare_local()` and produce no `top_level_statements`. This caused an index offset: exported statements after ambient declarations pointed past the valid range of the lowered statement list.

**Fix**: Added `Stmt::AmbientValueDecl { .. }` to the exclusion list in `lowers_to_top_level_statement()`, matching its actual behavior (no top-level statement produced during lowering).

**Results**: 10/14 files now pass. Remaining 4 fail with `FuncId out of range` — a different issue where function IDs are referenced but the program has 0 functions (likely JS-specific files with `@noemit` or JSDoc features).
