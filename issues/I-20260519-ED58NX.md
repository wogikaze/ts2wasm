## Fix applied (Round 2: InvariantViolation)

### Problem

4+ test262 Array tests (concat/copyWithin/flatMap) failed with `InvariantViolation/compiler-invariant: unresolved wasm call symbol: $array_ctor_with_length`. The native emitter's `emit_runtime_rest_array` synthesizes `WasmInstr::Call("$array_ctor_with_length")` and `WasmInstr::Call("$array_push_grow")` during codegen, but these are not `RuntimeCall` intrinsics in the IR, so the standard `build_runtime_link_plan` scan misses them.

### Fix

Added `program_has_any_array_new()` — a conservative scan of the full program IR for any `ArrayNew` expression. When found, `ArrayCtorWithLength` and `ArrayPushGrow` are registered in the synthetic-runtime set so the wasm module includes these functions.
