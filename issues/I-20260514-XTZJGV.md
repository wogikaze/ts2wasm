Title: Dispatch object literal methods after computed-key lowering
Summary: Computed-key object literals materialize method properties, but direct calls like obj.a() do not populate object_function_props and fail as Object.a.
Next: Teach computed-key object literal lowering/facts to retain callable method property metadata, or route calls through runtime property-get plus call for known function-valued properties.

---

## Notes

### 2026-05-14 discovery

- Reproduction fixture during computed-method parser work:
  - `fixtures/core-expressions/object-literal-computed-method.ts` with `console.log(obj.a())` or `console.log(obj.b())`
- Build diagnostic:
  - `error: [UnsupportedBuiltin/lowering] method \`Object.a\` not found`
- Root cause hypothesis: computed-key object literals lower through `lower_object_literal_expr_with_computed_keys`, producing a block expression rather than a plain `ObjectNew`. `function_props_for_lowered_object_expr` only extracts callable object properties from `ObjectNew`, so `object_function_props` is not populated for direct method dispatch.
